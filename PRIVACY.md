# Rotra Privacy Policy

Last updated: August 2026

Rotra is designed to perform Minecraft rotation analysis locally on the user's computer.

## Accounts

Rotra does not require a user account.

## Local Data

Rotra stores application settings, block patterns, analysis runs, checkpoints, and result files locally on the user's computer.

## Network Access

Rotra may open external links such as the official Kovex GitHub repository or Ko-fi support page when requested by the user.

Rotra does not sell user data.
