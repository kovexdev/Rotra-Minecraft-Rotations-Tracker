# Security

If you believe you have discovered a security issue in Rotra, please do not publish sensitive details publicly.

Report security issues to:

`devkovex@gmail.com`

Please include:

- Rotra version
- Windows version
- steps to reproduce
- relevant screenshots or logs

## Official Downloads

Official Rotra releases are distributed only through the official Kovex Rotra GitHub repository.

Always verify the SHA-256 checksum of downloaded installers when available.
